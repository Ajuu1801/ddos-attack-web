## 📌 Overview

This is a **Flask-based Python web app** that simulates a basic DDoS (Distributed Denial-of-Service) attack by sending concurrent HTTP GET requests to a specified URL using multiple threads.

> ❗ This project is designed **strictly for educational, ethical hacking, and testing purposes** on your own infrastructure or systems you have explicit permission to test.

## ✨ Features

- 🌐 Simple web interface (HTML form)
- 🧠 Multi-threaded HTTP request sender
- ⚙️ Adjustable bot count
- 📦 Lightweight and easy to set up

## 🛠️ Requirements

- Python 3.6 or higher
- `pip` (Python package manager)

### 🔧 Installation

```bash
git clone https://github.com/Ajuu1801/ddos-attack-web.git
cd ddos-attack-web
pip install -r requirements.txt

If requirements.txt is missing, manually install:
pip install flask requests


🚀 Usage
python app.py




Open your browser and go to http://localhost:5000
Enter:
✅ Target URL (e.g., https://example.com)
✅ Number of bot requests to simulate

Hit Start Attack to begin simulation
